# AIC 2026 · 城市场景视觉多模态目标检测

全球校园人工智能算法精英大赛“面向城市场景的视觉多模态目标检测”赛题项目，获 **2026 年省赛三等奖**。本仓库整理本人参与的模型训练、推理、评测与实验分析代码，以及历史训练配置。

任务涉及可见光、红外与深度信息下的 12 类城市目标检测。实验覆盖 YOLO、D-FINE、Co-DETR 等模型路线；这里发布的主要是本人的训练启动器、D-FINE 推理工具、YOLO 多模态实验模块和独立评测工具，第三方模型框架由上游提供。

## 工作内容

- 数据与多模态处理：模态读取、深度编码、融合实验及分组验证分析。
- 模型实验：YOLO 基线与多模态分支、D-FINE 训练启动及配置归档。
- 推理与输出：多尺度和翻转 TTA、按类 NMS、坐标转换及每图最多 100 框的提交格式检查。
- 评测与诊断：mAP@50–95、本地评测与 pycocotools 对照、分类别和分组误差分析。
