# 实验路线与结果口径

| 路线 | 归档内容 | 说明 |
| --- | --- | --- |
| YOLO 基线 | 训练、推理与数据配置 | 作为基础检测管线 |
| 多模态实验 | 读取、深度编码、融合与训练接口 | 实验分支，不表述为已经稳定优于 RGB |
| D-FINE | 训练启动器、TTA 推理与历史配置 | 模型主体来自上游 D-FINE |
| 评测分析 | mAP、本地格式检查、类别/分组诊断 | 本地验证和线上成绩分开看待 |

赛事结果：2026 年省赛三等奖。项目文档保留了小样本、模态负迁移、验证分布与隐藏测试不一致等实验经验；避免仅凭本地验证提升推断线上收益。Co-DETR 属于项目中探索过的路线，本仓库没有打包第三方 Co-DETR 代码或声称提供其全部训练环境。

`configs/archive/` 包含不同阶段、不同实验臂的历史配置，文件名可能带旧机器标签。它们不是全部获胜配置，也不保证相互可替换；使用前应逐项核对数据路径、权重、类别数、上游 includes 和推理尺度。
